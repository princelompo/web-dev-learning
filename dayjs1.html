📘 Jour 18 : Bases du JavaScript

Objectif : Maîtriser les bases du langage JavaScript (variables, types, opérateurs).

Formation 30 jours — HTML / CSS / JavaScript

1. Les variables

var, let, const

// var (ancienne méthode)
var nom = "Jean";
var age = 25;

// let (variable modifiable)
let ville = "Paris";
ville = "Lyon"; // Réaffectation possible

// const (constante)
const PI = 3.14159;
// PI = 3.14; // Erreur !

💡 Règle d'or :

  • Utiliser const par défaut
  • Utiliser let si la variable doit être réaffectée
  • Éviter var (ancienne méthode)

2. Les types de données

Types primitifs

// String
const nom = "Jean";
const message = `Bonjour ${nom}`;

// Number
const age = 25;
const prix = 19.99;

// Boolean
const estMajeur = true;
const estEnfant = false;

// Undefined
let x; // undefined

// Null
let y = null;

// Symbol
const id = Symbol("id");

// BigInt
const grand = 9007199254740991n;

Vérification des types

// typeof
console.log(typeof "texte"); // "string"
console.log(typeof 42); // "number"
console.log(typeof true); // "boolean"
console.log(typeof undefined); // "undefined"
console.log(typeof null); // "object" (bug historique)

⚠️ Attention :

  • typeof null retourne "object" (bug historique)
  • typeof [] retourne "object"
  • Utiliser Array.isArray() pour vérifier un tableau

3. Les opérateurs

Opérateurs arithmétiques

const a = 10;
const b = 3;

console.log(a + b); // 13 (addition)
console.log(a - b); // 7 (soustraction)
console.log(a * b); // 30 (multiplication)
console.log(a / b); // 3.333... (division)
console.log(a % b); // 1 (modulo)
console.log(a ** b); // 1000 (exponentiation)

Opérateurs de comparaison

// Égalité
console.log(5 == "5"); // true (conversion)
console.log(5 === "5"); // false (strict)

// Inégalité
console.log(5 != "5"); // false
console.log(5 !== "5"); // true

// Comparaisons
console.log(10 > 5); // true
console.log(10 >= 10); // true
console.log(5 < 10); // true
console.log(5 <= 5); // true

💡 Règle d'or :

  • Toujours utiliser === et !==
  • Éviter == et != (conversion implicite)

Opérateurs logiques

// ET (&&)
console.log(true && true); // true
console.log(true && false); // false

// OU (||)
console.log(true || false); // true
console.log(false || false); // false

// NON (!)
console.log(!true); // false
console.log(!false); // true

Opérateur ternaire

const age = 18;
const statut = age >= 18 ? "Majeur" : "Mineur";
console.log(statut); // "Majeur"

4. Conversion de types

Conversion explicite

// Vers String
String(42); // "42"
42.toString(); // "42"

// Vers Number
Number("42"); // 42
parseInt("42px"); // 42
parseFloat("3.14"); // 3.14

// Vers Boolean
Boolean(1); // true
Boolean(0); // false
Boolean(""); // false
Boolean("texte"); // true

⚠️ Falsy values :

Ces valeurs sont falsy (deviennent false en booléen) : false, 0, "", null, undefined, NaN
