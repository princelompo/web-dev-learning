📍 Jour 12 : Positionnement

Objectif : Maîtriser les différentes valeurs de positionnement (static, relative, absolute, fixed, sticky).

Formation 30 jours — HTML / CSS / JavaScript

1. Position: static (défaut)

Static (défaut)

L'élément suit le flux normal de la page. top, right, bottom, left n'ont aucun effet.

💡 static : Valeur par défaut de tous les éléments.

2. Position: relative

Décalage positif (top, left)

Relative (top:20px, left:30px)

L'élément est décalé de 20px vers le bas et 30px vers la droite. L'espace d'origine est conservé.

Décalage négatif

Relative (top:-20px, left:-30px)

L'élément est décalé de 20px vers le haut et 30px vers la gauche. L'espace d'origine est conservé.

💡 relative :

  • Positionné par rapport à sa position normale
  • Conserve son espace dans le flux
  • Utile comme parent pour les éléments absolute

3. Position: absolute

Positionnement par rapport au parent

Absolute (top:20px, right:20px)

L'élément est positionné par rapport au parent positionné (ce conteneur a position: relative).

Centrage avec absolute

Absolute (centré)

top: 50%; left: 50%; transform: translate(-50%, -50%)

En bas à gauche

Absolute (bottom:20px, left:20px)

bottom: 20px; left: 20px

⚠️ Important :

  • L'élément est retiré du flux (les autres éléments se repositionnent)
  • Positionné par rapport au parent positionné le plus proche
  • Si aucun parent positionné, par rapport au viewport
  • Le parent doit avoir position: relative (ou autre)

4. Position: fixed

Exemple en cours d'utilisation :

  • Le menu en haut de la page est en position: fixed
  • Il reste fixe lors du défilement

🔵 Bouton fixe

Un bouton est en position: fixed en bas à droite de la page. Il reste visible lors du défilement.

💡 fixed :

  • Positionné par rapport à la fenêtre (viewport)
  • Retiré du flux
  • Reste fixe lors du défilement
  • Utile pour : menus, boutons d'action, popups

5. Position: sticky

📌 En-tête sticky (top: 70px)

Ce contenu défile normalement. L'en-tête reste collé quand on le dépasse.

position: sticky; top: 70px;

Faites défiler la page pour voir l'effet sticky. L'en-tête reste collé tant que le conteneur est visible.

(Ajout de contenu pour le défilement)

💡 sticky :

  • Alterne entre relative et fixed
  • Se fixe quand l'élément atteint la valeur définie (top)
  • Reste collé tant que le conteneur est visible
  • Utile pour : en-têtes de table, sections, menus

6. Z-index (ordre d'empilement)

z-index: 1
z-index: 2
z-index: 3
z-index: -1

Plus le z-index est élevé, plus l'élément est proche de l'utilisateur.

Ordre : z-index: -1 (derrière) → 1 → 2 → 3 (devant)

⚠️ Règles du z-index :

  • Ne fonctionne que sur les éléments positionnés
  • Valeurs : nombres entiers (positifs ou négatifs)
  • Plus la valeur est élevée, plus l'élément est devant
  • Les enfants héritent du contexte d'empilement du parent
