🔀 Jour 19 : Structures de contrôle

Objectif : Maîtriser les conditions (if, switch) et les boucles (for, while) en JavaScript.

Formation 30 jours — HTML / CSS / JavaScript

1. Les conditions

if, else if, else

// Exemple : déterminer la mention
const note = 15;

if (note >= 16) {
    console.log("Mention Très Bien");
} else if (note >= 14) {
    console.log("Mention Bien");
} else if (note >= 12) {
    console.log("Mention Assez Bien");
} else {
    console.log("Mention Passable");
}

// Affiche : "Mention Bien"

switch

// Exemple : jour de la semaine
const jour = 3;

switch (jour) {
    case 1:
        console.log("Lundi");
        break;
    case 2:
        console.log("Mardi");
        break;
    case 3:
        console.log("Mercredi");
        break;
    default:
        console.log("Jour invalide");
}

// Affiche : "Mercredi"

💡 Différence entre if et switch :

  • if : pour des conditions complexes (comparaisons, valeurs multiples)
  • switch : pour comparer une valeur avec plusieurs cas précis
  • switch utilise une comparaison stricte (===)
  • Ne pas oublier break dans un switch (fallthrough)

2. Les boucles

for

// Boucle de 0 à 4
for (let i = 0; i < 5; i++) {
    console.log(i);
}

// Boucle avec un pas de 2
for (let i = 0; i < 10; i += 2) {
    console.log(i);
}

while

// Boucle while
let compteur = 0;
while (compteur < 5) {
    console.log(compteur);
    compteur++;
}

do...while

// Boucle do...while (exécutée au moins une fois)
let x = 10;
do {
    console.log("Exécuté !");
} while (x < 5);
// Affiche "Exécuté !" une fois

💡 Comparaison des boucles :

  • for : nombre d'itérations connu
  • while : nombre d'itérations inconnu (vérification en début)
  • do...while : exécutée au moins une fois (vérification en fin)

3. for...in et for...of

for...in (parcours des propriétés)

// Parcours d'un objet
const personne = {
    nom: "Jean",
    age: 25,
    ville: "Paris"
};

for (const cle in personne) {
    console.log(`${cle}: ${personne[cle]}`);
}
// Affiche : nom: Jean, age: 25, ville: Paris

for...of (parcours des valeurs)

// Parcours d'un tableau
const fruits = ["pomme", "banane", "orange"];

for (const fruit of fruits) {
    console.log(fruit);
}
// Affiche : pomme, banane, orange

// Parcours d'une chaîne
const nom = "Jean";
for (const lettre of nom) {
    console.log(lettre);
}
// Affiche : J, e, a, n

⚠️ Différence :

  • for...in : parcourt les clés (objets)
  • for...of : parcourt les valeurs (itérables)
  • Ne pas utiliser for...in pour les tableaux (préférer for...of)

4. break, continue, labels

break (sortie de boucle)

// Sortie à i = 5
for (let i = 0; i < 10; i++) {
    if (i === 5) {
        break;
    }
    console.log(i);
}
// Affiche : 0, 1, 2, 3, 4

continue (passe à l'itération suivante)

// Saute les nombres pairs
for (let i = 0; i < 10; i++) {
    if (i % 2 === 0) {
        continue;
    }
    console.log(i);
}
// Affiche : 1, 3, 5, 7, 9

💡 Utilisation :

  • break : sort immédiatement de la boucle
  • continue : passe à l'itération suivante
  • Les labels permettent de sortir de boucles imbriquées
