📊 Jour 21 : Tableaux et méthodes

Objectif : Maîtriser la création et la manipulation des tableaux avec toutes leurs méthodes.

Formation 30 jours — HTML / CSS / JavaScript

1. Création et méthodes de base

Création de tableaux

// Syntaxe littérale
const fruits = ["pomme", "banane", "orange"];

// Constructeur
const nombres = new Array(1, 2, 3);

// Array.from()
const lettres = Array.from("Bonjour");
// ["B", "o", "n", "j", "o", "u", "r"]

Méthodes de base (push, pop, shift, unshift)

// push : ajouter à la fin
fruits.push("kiwi"); // ["pomme", "banane", "orange", "kiwi"]

// pop : supprimer à la fin
const dernier = fruits.pop(); // "kiwi"

// unshift : ajouter au début
fruits.unshift("fraise");

// shift : supprimer au début
const premier = fruits.shift(); // "fraise"

2. Méthodes d'itération

forEach, map, filter, reduce

// forEach : parcourir
fruits.forEach((fruit, i) => {
    console.log(`${i}: ${fruit}`);
});

// map : transformer
const longueurs = fruits.map(fruit => fruit.length);
// [5, 6, 6]

// filter : filtrer
const longues = fruits.filter(fruit => fruit.length > 5);
// ["banane", "orange"]

// reduce : réduire
const total = fruits.reduce((acc, fruit) => acc + fruit.length, 0);
// 17

💡 Méthodes d'itération :

  • forEach : parcourt sans retour
  • map : transforme chaque élément
  • filter : garde les éléments qui satisfont une condition
  • reduce : réduit à une valeur unique
  • some / every : vérifications
