4. Les chemins de fichiers

4.1 Structure des dossiers

// Structure de dossiers / (racine du site) ├── index.html ├── contact.html ├── images/ │ ├── photo.jpg │ └── gallery/ │ └── galerie.jpg ├── articles/ │ ├── article1.html │ └── article2.html └── css/ └── style.css

4.2 Tableau des chemins

Chemin Description Exemple
/ Racine du site /images/photo.jpg
. Dossier courant ./style.css
.. Dossier parent ../index.html
./ Dossier courant (explicite) ./images/photo.jpg
../../ Deux dossiers parents ../../index.html

4.3 Exemples concrets

Depuis /articles/article1.html

  • index.html → ../index.html
  • contact.html → ../contact.html
  • photo.jpg → ../images/photo.jpg
  • galerie.jpg → ../images/gallery/galerie.jpg

Depuis /images/gallery/

  • index.html → ../../index.html
  • contact.html → ../../contact.html
  • photo.jpg → ../photo.jpg
