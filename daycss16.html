💡 Pseudo-classes avancées :

  • :nth-child() : sélectionne le nième enfant
  • :nth-of-type() : sélectionne le nième élément de son type
  • :not() : négation
  • :has() : contient un élément spécifique
  • :focus-within : focus à l'intérieur
  • :target : élément ciblé par l'URL
  • :is() : sélection multiple
  • :where() : comme :is() mais spécificité 0

4. Pseudo-éléments avancés

::first-letter (lettrine)

L a lettrine est une technique typographique qui permet de mettre en valeur la première lettre d'un paragraphe. Elle est souvent utilisée dans les livres et les magazines.

::first-line

La première ligne de ce paragraphe est stylée différemment. Cette technique est utile pour mettre en valeur le début d'un texte ou pour créer des effets typographiques.

::selection

Sélectionnez ce texte pour voir l'effet de ::selection. La couleur de fond et la couleur du texte changent.
