💡 Les 3 piliers :

  • Grilles fluides : unités relatives (%, fr, rem, vw/vh)
  • Images flexibles : max-width: 100%; height: auto;
  • Media queries : points de rupture adaptés

💡 Classes utilitaires :

  • .hide-on-mobile : caché sur mobile
  • .show-on-mobile : visible uniquement sur mobile
  • .no-print : caché à l'impression

6. Media queries avancées

💡 Caractéristiques avancées :

  • (prefers-color-scheme: dark) — Mode sombre
  • (orientation: portrait) — Orientation portrait
  • (hover: hover) — Appareil avec souris
  • (pointer: fine) — Pointeur précis
  • (prefers-reduced-motion: reduce) — Réduction de mouvement
