📦 Jour 9 : Modèle de boîte (Box Model)

Objectif : Maîtriser le Box Model et ses composants (content, padding, border, margin).

Formation 30 jours — HTML / CSS / JavaScript

1. Le Box Model

MARGIN (marge extérieure)
BORDER (bordure)
PADDING (rembourrage intérieur)
CONTENT (contenu)

💡 Le Box Model en bref :

  • Content : le contenu visible
  • Padding : espace entre le contenu et la bordure
  • Border : bordure autour du padding
  • Margin : espace entre la bordure et les autres éléments

2. Box-sizing

content-box vs border-box

content-box
width: 300px
padding: 20px
border: 5px
Total: 350px
border-box
width: 300px
padding: 20px
border: 5px
Total: 300px

⚠️ Recommandation : Utilisez toujours box-sizing: border-box sur tous les éléments pour faciliter les calculs de mise en page.

3. Padding

Différentes syntaxes

padding: 20px; (tous les côtés)
padding: 10px 30px; (haut/bas | gauche/droite)
padding: 5px 15px 25px; (haut | côtés | bas)
padding: 5px 10px 15px 20px; (haut | droite | bas | gauche)
padding: 5%; (pourcentage du parent)

💡 À retenir :

  • Le padding est intérieur (entre contenu et bordure)
  • Il agrandit la boîte (sauf avec border-box)
  • Les pourcentages sont calculés par rapport à la largeur du parent

5. Margin

Différentes syntaxes

margin: 20px; (tous les côtés)
margin: 10px 40px; (haut/bas | gauche/droite)
margin: 10px auto; (centrage horizontal)
margin: -10px; (marge négative)

⚠️ Fusion des marges (Margin Collapse) :

Les marges verticales de deux éléments adjacents se fusionnent. Seule la plus grande est conservée.

Exemple : margin-bottom: 30px + margin-top: 20px = 30px

6. Outline

outline simple
Ne prend pas d'espace

outline: 3px dashed

💡 Différence Border vs Outline :

  • Border : prend de l'espace, fait partie du Box Model
  • Outline : ne prend pas d'espace, se superpose
  • L'outline est souvent utilisée pour le :focus
